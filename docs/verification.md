## 执行器锁

单机本地 SQLite。锁同时记录进程 ID 和随机所有者标识。即使心跳过期，只要旧进程仍存活，就拒绝接管，避免被暂停的旧进程恢复后继续付款。付款前以及异步步骤结束后检查执行权，失去执行权不覆盖新状态。

不要把数据库放在多主机共享盘或用多个容器实例同时挂载运行。若进程 ID 被系统重用而锁保守拒绝启动，应由管理员核查后处理，不能自动删除锁绕过检查。
